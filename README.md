# Лабораторная работа № 2

Модуль расчёта бонусов из мобильного проекта «Форштадт» и десять unit-тестов. Учебный багрепорт по VLC находится в `BUG_REPORT.md`.

## Запуск

Требуется Node.js 22.18.0 или новее. Сторонние пакеты не нужны.

```sh
npm test
```

В VS Code откройте папку проекта и выберите в палитре команд **Tasks: Run Test Task**. Задача вызывает ту же команду.

`src/loyalty.ts` содержит исходный метод `purchase`. Суммы передаются в копейках, баллы — целыми числами. Тесты проверяют лимиты списания, округление, начисление и ошибочные аргументы.
